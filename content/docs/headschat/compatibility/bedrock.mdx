## Bedrock Edition

Bedrock clients can't see custom components, as they where not designed to. However, HeadsChat will send a fallback message to them, so they won't see the fancy components but at least they will see something instead of an ugly `[PLAYER'S HEAD]` text.

### Fallback

By default, is set to `""`. If you want to show a custom glyph, just replace it!
