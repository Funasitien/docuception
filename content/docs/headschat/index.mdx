## Download HeadsChat
At the moment, HeadsChat is only available on Modrinth. You can download the latest version of HeadsChat from [the following link](https://modrinth.com/plugin/headschat)

## Installation

<Steps>


<Step>
  Download the latest version of HeadsChat from the link above.
</Step>
<Step>
  Place the downloaded JAR file into your server's `plugins` directory.
</Step>
<Step>
  Start your server to generate the configuration files.
</Step>
<Step>
  Stop the server and open the `config.yml` file located in the `plugins/HeadsChat` directory.
</Step>
<Step>
  Customize the configuration settings according to your preferences.
</Step>
<Step>
  Start your server again to apply the changes.
</Step>
</Steps>
