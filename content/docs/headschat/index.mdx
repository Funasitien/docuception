## Download HeadsChat
At the moment, HeadsChat is only available on Modrinth. You can download the latest version of HeadsChat from [the following link](https://modrinth.com/plugin/headschat)

## Installation
1. Download the latest version of HeadsChat from the link above.
2. Place the downloaded JAR file into your server's `plugins` directory.
3. Start your server to generate the configuration files.
4. Stop the server and open the `config.yml` file located in the `plugins/HeadsChat` directory.
5. Customize the configuration settings according to your preferences.
6. Start your server again to apply the changes.
